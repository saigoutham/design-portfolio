# Getting the art

Rungs, in the order to try them. `npm run probe` writes which are open today to `system/capabilities.json`.

1. **Code** (always open, always first). three.js/R3F with real shaders, canvas, SVG, GSAP. Load r3f-materials, r3f-shaders, r3f-lighting and r3f-postprocessing, and read `library/motionsites` and `library/scroll-craft/references/hero-depth.md`, before writing a scene.
2. **Supplied.** The user's files, or stills the user generates on a phone from prompts you write: one series, one chat, same light and background, 3:2 landscape plus 2:3 portrait for phones. Judge each image, then use it as a material on coded geometry (a texture on a 3D surface), never as a flat layer moved by a mask.
3. **Generated** (needs an image API key in the workspace). Same rule as supplied.
4. **Sourced** (stock, if reachable). Licence in `docs/art.md`.
5. **Rendered** (Blender, if installed). Slow on 2 cores.

Every asset gets its origin and licence in the site's `docs/art.md`. AI-generated images are labelled as such.
