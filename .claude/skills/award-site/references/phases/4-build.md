# Phase 4: build

Everything after the hero. Packs: `copy`, `taste`, `video`; `seo` near the end; `dev` for worktree and branch helpers.

1. **Spec (you).** `docs/spec.md`: one table row per section: purpose, content, layout at desktop and phone, motion (trigger, duration, easing), assets needed, acceptance check. Plus the scroll score: where the page pins, how long, where it rests. Keep it under two pages.
2. **Three tracks in one message:**
   - **Copy** (sonnet): copywriting from `PRODUCT.md`, then copy-editing. Final text for every section in `docs/copy.md`. No invented facts.
   - **Assets** (sonnet): the remaining art by the proven route, encoded and sized, each logged in `docs/art.md`.
   - **Sections** (sonnet, one agent per independent section, each in its own worktree): build from the spec and `DESIGN.md` with the gsap skills. Sections that share a pinned scene are one task.
3. **Merge.** cavecrew-reviewer reads every diff. systematic-debugging when a bug survives one fix.
4. **Polish (you).** impeccable `polish` on the whole page; review-animations on the motion; reduced-motion and keyboard pass.
5. Each finished section passes the floor's automatic fails and the taste gate before it's shown.
