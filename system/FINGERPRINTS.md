# Fingerprints

One row per site, so the next site can prove it's a different page and not a reskin. Format and rules come from scroll-craft (`library/scroll-craft/references/uniqueness.md`).

**A new site must differ from every row on at least 4 of the 6 dimensions** (grammar, navigation, hero, act shape, close, signature move), against each row on its own, not on average. If a plan fails, change the plan. Never edit a row to make room.

`new-site` adds a `planned` row; stage 9 replaces it with the real values.
