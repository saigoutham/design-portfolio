# Lessons

One line per lesson a real jury taught, specific enough to change a future decision. Stages 2 and 3 read this before every new site.

Format: `- <date> · <site> · <what was rewarded or punished> → <what to do differently>`

- 2026-11-09 · diwali-festival-of-lights · every stage passed but the hero was prototype-grade: art hand-drawn in SVG, light from CSS gradients, one agent building alone, no critique before the user saw it → source or render real art before coding the hero, orchestrate tracks from stage 4, run references/floor.md before anything is shown.
- 2026-11-10 · healthy-watermelon-soda · four stages and ~260k tokens before the first visual, which then failed: the concept needed a photoreal fruit, and the workspace had no image API, no reachable photo sites and CPU-only Blender. A 137k-token agent polished the failing route for three passes → probe the art ladder at the start, approve a concept only with a passing art proof, cap every agent (40k, 2 attempts), switch routes instead of polishing.
- 2026-11-10 · system · ui-ux-pro-max proposed black-and-gold luxury for a fruit soda twice; 8 planned skill steps were skipped on one site because the skills weren't installed → v4: impeccable leads design, 14 core skills, everything else is a pack that must earn its place by running.
- 2026-11-10 · healthy-watermelon-soda · with no browser, no image key and no reachable photo sites, two art agents (code and Blender 3D type) scored 4/10 and 3/10 for 160k tokens → the probe now flags when no rung can make hero art, and phase 1 asks for supplied files or a key before any art agent runs.
