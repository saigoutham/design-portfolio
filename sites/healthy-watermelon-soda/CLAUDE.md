# Healthy Watermelon Soda

A personal concept site built with the award-site pipeline.
Start every session with `/award-site status healthy-watermelon-soda`: it runs `npm run phase -- healthy-watermelon-soda` from the repo root, and you work the open steps in order.

Context, read only when the current step needs it: PRODUCT.md, DESIGN.md, docs/brief.md, docs/research.md, docs/concept.md, docs/art.md, docs/spec.md. Decisions and the phase log: docs/decisions.md.
